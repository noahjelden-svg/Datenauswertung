Dies ist eine Github Repo die sich mit Wettervorhersage per KI befasst und im Rahmen eines NExT Projektes des Hans-Freudenberg Gymnasiums stattfindet. 
Ziel ist es ein Neurales Netzwerk zu bauen welches Daten von verschiedenen Sensoren und Wetterdaten aufnimmt und dadurch den Verlauf von Wetter vorhersagt.
Zusätzlich befasst sich dieses Projekt mit der Darstellung und dem Speichern von Daten.
